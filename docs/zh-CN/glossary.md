# 术语表

[English](../en/glossary.md)

<a id="sdk"></a>

## SDK（软件开发工具包）

Quantum.Plugin.Abstraction 提供的已发布开发抽象。

<a id="rpc"></a>

## RPC（远程过程调用）

通过生成的客户端和服务端处理的命名请求。

<a id="nof"></a>

## NOF 应用框架

提供处理器生成、依赖注入、映射和持久化的框架。

<a id="cli"></a>

## CLI（命令行界面）

通过命令操作的程序；Codex 需要单独安装并登录。

<a id="ci"></a>

## CI（持续集成）

自动执行构建、格式、测试和打包检查。

<a id="clr"></a>

## CLR（公共语言运行时）

.NET 运行时；程序集与命名空间名称属于兼容性契约。

<a id="ui"></a>

## UI（用户界面）

Blazor 页面、后台代码、样式和本地化资源。

<a id="css"></a>

## CSS（层叠样式表）

样式表，包括生成的组件作用域合并样式。
